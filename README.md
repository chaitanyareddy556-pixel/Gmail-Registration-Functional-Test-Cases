# Gmail Registration Module – Functional Testing Test Cases

## Project Overview
This project contains manual functional testing test cases for the Gmail Registration Module. The test cases are documented in Microsoft Excel to verify registration form functionality, field validations, and expected application behavior.

## Project Objectives
- Verify the registration page loads correctly.
- Validate mandatory fields and input formats.
- Test email and password validation.
- Verify password masking and field behavior.
- Check duplicate username handling.
- Verify terms and conditions validation.
- Validate successful registration and email confirmation behavior.

## Project Details
- **Project Name:** Gmail Registration Module
- **Module Name:** Registration Module
- **Testing Type:** Functional Testing
- **Testing Level:** Functional validation of individual registration features
- **Testing Approach:** Positive and negative testing
- **Test Case Format:** Microsoft Excel
- **Testing Environment:** Windows 11, Google Chrome
- **Author:** Chaitanya

## Test Scenarios Covered
The Excel sheet includes test scenarios for:

1. Registration page load
2. Empty field validation
3. Email format validation
4. Password strength validation
5. Password and confirmation password matching
6. Successful registration
7. Duplicate username validation
8. Terms of service agreement
9. Optional mobile number validation
10. Invalid date format
11. Special characters in the name field
12. Password field masking
13. Email auto-complete behavior
14. Password copy-paste restriction
15. Field focus order using the Tab key
16. Email case sensitivity
17. Password expiry validation, where applicable
18. Email confirmation verification
